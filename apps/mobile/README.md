# Mobile

M1 provides a blank React Native 0.86.2 shell with Android and iOS native projects.

From the repository root:

```text
pnpm --filter @guided-discovery/mobile start
pnpm --filter @guided-discovery/mobile android
pnpm --filter @guided-discovery/mobile ios
```

Android requires an emulator or connected device. iOS requires macOS, Xcode, and CocoaPods.

The shell contains no product screens, authentication, storage, AI behavior, or business logic.

# M2 Database Entity Specification

Status: Final

## Global persistence rules

- PostgreSQL is the system of record. Each service owns a database/schema and credentials; cross-service foreign keys, joins, triggers, and writes are prohibited.
- Primary keys are UUIDs generated by the owning service. Timestamps are `timestamptz` in UTC. Mutable aggregates have `version integer not null check (version > 0)`.
- User-owned tables contain `owner_id uuid not null`. Ownership fields are indexed but never treated as authorization.
- Mutable user content includes `created_at`, `updated_at`, optional `deleted_at`, optional `purge_after`, and positive `version`.
- Soft-deleted rows are excluded by repository-level mandatory predicates. Partial unique indexes apply only where `deleted_at is null`.
- Enum columns use service-owned database enums or check constraints whose allowed values exactly match OpenAPI and AsyncAPI.
- Content columns are encrypted through the approved application encryption adapter. Key references are opaque metadata, never key material.
- Every service that publishes or consumes events owns `outbox_events`, `inbox_events`, and `dead_letter_events`. Every command endpoint owns `idempotency_records`. Definitions appear under Reliability entities.

## Memory Service

### `memory_categories`

`id uuid PK`, `key varchar(64) not null unique`, `display_name varchar(100) not null`, `default_sensitivity varchar(32) not null`, `is_system boolean not null default true`, `is_active boolean not null default true`, `version integer not null`, `created_at`, `updated_at`. M2 requires `is_system=true`; user-owned categories are forbidden. Index: unique lower-case key.

### `memories`

`id uuid PK`, `owner_id uuid not null`, `category_id uuid not null FK memory_categories(id) restrict`, `current_version_id uuid null`, `state varchar(32) not null`, `importance numeric(4,3) not null check 0..1`, `sensitivity varchar(32) not null`, `verification_status varchar(32) not null`, `permission_policy_ref varchar(128) not null`, `permission_policy_version integer not null`, `retention_policy_ref varchar(64) not null`, `user_confirmed_at timestamptz null`, `archived_at timestamptz null`, `deletion_version integer not null default 0`, `deleted_at timestamptz null`, `purge_after timestamptz null`, `purge_status varchar(32) not null`, `legal_hold_ref varchar(128) null`, `created_at`, `updated_at`, `version`.

Constraints enforce state/timestamp consistency, paired policy fields, confirmation timestamp only for confirmed status, and purge fields for deletion states. After table creation, `current_version_id` references `memory_versions(id)` deferrably. Indexes: `(owner_id, state, created_at desc, id desc)`, `(owner_id, category_id, state, created_at desc)`, `(purge_status, purge_after)` for purge work, and `(owner_id, deletion_version)`.

### `memory_versions`

`id uuid PK`, `memory_id uuid not null FK memories(id) cascade-on-purge`, `version_number integer not null`, encrypted `title_ciphertext bytea`, encrypted `summary_ciphertext bytea`, encrypted `purpose_ciphertext bytea`, `source_type varchar(32) not null`, encrypted optional `source_ref_ciphertext bytea`, `originated_at timestamptz null`, `confidence numeric(4,3) not null check 0..1`, `verification_status varchar(32) not null`, encrypted optional `correction_reason_ciphertext bytea`, `encryption_state varchar(32) not null`, `encryption_key_ref varchar(256) not null`, `actor_id uuid not null`, `created_at timestamptz not null`. Unique `(memory_id, version_number)`. Versions are append-only; update/delete grants are denied to runtime except the purge role.

### `memory_links`

`id uuid PK`, `owner_id uuid not null`, `source_memory_id uuid not null FK memories(id)`, `target_memory_id uuid not null FK memories(id)`, `relationship_type varchar(32) not null`, `created_at`, `updated_at`, `deleted_at null`, `version`. Check source differs from target. Unique active `(source_memory_id,target_memory_id,relationship_type)`. Symmetric relationships store the lexicographically smaller ID as source. Index both endpoints with `deleted_at is null`.

### `memory_deletion_ledger`

`memory_id uuid PK`, `owner_id uuid not null`, `deletion_version integer not null`, `deleted_at`, `purge_after`, `legal_hold_ref null`, `purge_status`, `last_error_code null`, `updated_at`. It is content-free. Index `(purge_status,purge_after)` and retain the post-purge tombstone under `T1_TOMBSTONE`.

This ledger is the sole physical persistence for memory deletion tombstones. “Tombstone” is an architectural concept, not a separate table; implementations must not create `memory_tombstones`.

## Planning Service

### `itineraries`

`id`, `owner_id`, `title varchar(200)`, `status` (`DRAFT|ACCEPTED|COMPLETED|CANCELLED`), `start_date date null`, `end_date date null`, `budget_amount numeric(14,2) null`, `budget_currency char(3) null`, encrypted `notes_ciphertext bytea null`, `created_at`, `updated_at`, `deleted_at`, `purge_after`, `version`. Checks enforce date order and paired budget fields. Index `(owner_id,status,created_at desc,id desc)` and `(owner_id,start_date)` for active rows.

### `itinerary_items`

`id`, `itinerary_id FK cascade-on-purge`, `position integer >=0`, `title varchar(200)`, `starts_at null`, `ends_at null`, `location_reference varchar(500) null`, encrypted `notes_ciphertext null`, `status` (`PLANNED|COMPLETED|CANCELLED`), common timestamps, `deleted_at`, `version`. Unique active `(itinerary_id,position)`; check end after start.

### `reservations`

`id`, `itinerary_id FK cascade-on-purge`, `provider_name varchar(200)`, encrypted `reference_ciphertext null`, `starts_at null`, `ends_at null`, `status` (`PLANNED|CONFIRMED|CANCELLED`), common timestamps, `deleted_at`, `version`. Check end after start; index `(itinerary_id,status)`.

### `travel_checklists`

`id`, `itinerary_id FK cascade-on-purge`, `position integer >=0`, `title varchar(200)`, `status` (`PENDING|COMPLETE`), `completed_at null`, common timestamps, `deleted_at`, `version`. Status/timestamp consistency and unique active `(itinerary_id,position)`.

## Navigation Service

### `destinations`

`id`, nullable `owner_id`, `provider varchar(64)`, `provider_reference varchar(256)`, `name varchar(200)`, `latitude numeric(10,7)`, `longitude numeric(10,7)`, `timezone varchar(64)`, `accessibility jsonb`, `source_version integer`, `created_at`, `updated_at`, `deleted_at`, `version`. Unique active `(provider,provider_reference)`; geospatial range checks. Shared provider data has null owner and contains no user history.

### `routes`

`id`, nullable `owner_id`, `provider`, `provider_reference`, `origin_destination_id FK`, `destination_id FK`, `travel_mode`, `distance_meters`, `duration_seconds`, encrypted `polyline_ciphertext`, `accessibility jsonb`, `valid_from`, `valid_until null`, `source_version`, common timestamps, `deleted_at`, `version`. Unique active provider reference; validity/range checks; indexes on destinations and validity.

### `trips`

`id`, `owner_id`, `state` (`ACTIVE|COMPLETED|CANCELLED`), `destination_id`, nullable `active_session_id`, `started_at`, `completed_at null`, `cancelled_at null`, `outcome` (`COMPLETED|CANCELLED`) null, common timestamps, `deleted_at`, `purge_after`, `version`. Partial unique index permits one active trip per owner. State/timestamp checks.

### `navigation_sessions`

`id`, `trip_id FK`, `owner_id`, `route_id FK`, `destination_id FK`, `travel_mode`, `state` (`ACTIVE|COMPLETED|CANCELLED`), `started_at`, `ended_at null`, `stop_reason` (`COMPLETED|CANCELLED`) null, common timestamps, `deleted_at`, `version`. Partial unique one active session per trip and per owner. Future paused/replaced states require a later migration.

### `visited_locations`

`id`, `trip_id FK`, `owner_id`, `destination_id null`, encrypted coordinates, `visited_at`, common timestamps, `deleted_at`, `version`. Unique `(trip_id,visited_at,id)`; precise location always sensitive.

### `landmarks`

`id`, nullable `owner_id`, `destination_id null`, provider/reference, name, encrypted coordinates when user-owned, accessibility JSON, source version, common timestamps, `deleted_at`, `version`. Unique active provider reference.

## Recommendation Service

### `recommendations`

`id`, `owner_id`, `category varchar(64)`, encrypted `title_ciphertext`, encrypted `summary_ciphertext`, encrypted `rationale_ciphertext`, `status` (`AVAILABLE|ACCEPTED|REJECTED|DISMISSED|IGNORED|EXPIRED`), `confidence numeric(4,3)`, `available_at`, `expires_at null`, `permission_policy_ref varchar(128) not null`, `permission_version integer not null check (permission_version > 0)`, `provenance jsonb`, common timestamps, `deleted_at`, `purge_after`, `version`. Index `(owner_id,status,available_at desc,id desc)` and expiry work `(status,expires_at)`.

The policy reference and version are resolved authoritatively through Permission Service before insertion and do not independently grant access. Structured safety and accessibility metadata is not persisted in M2.5; only the approved scalar score factors are stored in `recommendation_scores`.

### `recommendation_history`

`id`, `recommendation_id FK cascade-on-purge`, `owner_id`, `from_status null`, `to_status`, `actor_type` (`USER|SYSTEM|SERVICE`), `actor_id null`, `reason_code null`, `event_id uuid not null`, `occurred_at`, `subject_version`. Append-only; unique `(recommendation_id,subject_version)` and unique `event_id`.

### `recommendation_scores`

`id`, `recommendation_id FK cascade-on-purge`, `factor`, `score numeric(4,3)`, `source_version`, `created_at`. Unique `(recommendation_id,factor)`.

## Documentation Service

### `journals`

`id`, `owner_id`, encrypted `title_ciphertext`, encrypted `description_ciphertext null`, nullable cross-service `trip_id`, `visibility` fixed `PRIVATE`, `permission_policy_ref varchar(128) not null`, `permission_policy_version integer not null check (permission_policy_version > 0)`, `started_at null`, `ended_at null`, common timestamps, `deleted_at`, `purge_after`, `version`. Check end after start. Index `(owner_id,created_at desc,id desc)` and `(owner_id,trip_id)` active rows. Permission fields are resolved and validated server-side through Permission Service, never accepted from public DTOs, and do not independently grant access.

### `journal_entries`

`id`, `journal_id FK cascade-on-purge`, `position`, `type`, encrypted `content_ciphertext null`, nullable `media_reference_id FK journal_media_references(id)`, `occurred_at`, encrypted `location_reference_ciphertext null`, common timestamps, `deleted_at`, `version`. Unique active `(journal_id,position)`. Text entries require content and no media-reference ID; reference entries require no content and an active same-journal media-reference ID whose kind matches the entry type. The foreign key is added after both child tables exist and must not permit a cross-journal reference.

### `journal_media_references`

`id`, `journal_id FK`, nullable `entry_id FK`, cross-service `media_id uuid`, `media_kind` (`VOICE|PHOTO|VIDEO`), encrypted `caption_ciphertext null`, `position`, common timestamps, `deleted_at`, `version`. No object URL or binary. Unique active `(journal_id,media_id,entry_id)`.

### `reflections`

`id`, `journal_id FK`, nullable `entry_id FK`, encrypted `text_ciphertext`, `occurred_at`, `position`, common timestamps, `deleted_at`, `version`. Unique active `(journal_id,position)`.

Timeline is a query over entries, media references, reflections, and journal boundaries; it is not persisted.

## Notification Service

### `notifications`

`id`, `owner_id`, `kind`, `channel`, encrypted `recipient_ref_ciphertext`, encrypted `title_ciphertext`, encrypted `body_ciphertext`, `status` (`DRAFT|SCHEDULED|QUEUED|PROCESSING|DELIVERED|FAILED|CANCELLED|EXPIRED`), `scheduled_for`, `expires_at null`, `queued_at null`, `processing_at null`, `delivered_at null`, `failed_at null`, `cancelled_at null`, `read_at null`, `permission_policy_ref`, `permission_policy_version`, `provenance jsonb`, common timestamps, `deleted_at`, `purge_after`, `version`. Lifecycle timestamp checks; indexes `(owner_id,status,created_at desc,id desc)` and `(status,scheduled_for)`.

### `notification_history`

`id`, `notification_id FK cascade-on-purge`, `owner_id`, `from_status null`, `to_status`, `actor_type`, `actor_id null`, `error_code null`, `event_id uuid not null`, `occurred_at`, `subject_version`. Append-only; unique `(notification_id,subject_version)` and unique `event_id`.

## Search Service

### `search_index_metadata`

`id`, `resource_type`, `index_alias`, `physical_index_name`, `schema_version`, `ranking_profile_version`, `status` (`PENDING|BUILDING|READY|FAILED|REBUILDING`), `document_count bigint`, `last_rebuilt_at null`, `last_error_code null`, common timestamps, `version`. Unique `(resource_type,index_alias)`.

### `search_aggregate_metrics`

The earlier conceptual `search_logs` table is not created because ADR-0010 prohibits its safe identifying inputs. No Search entity stores queries or hashes. Aggregate rows contain `id`, `window_start`, `window_end`, `resource_type`, `availability_status`, bucketed `result_count_band`, `request_count`, `latency_bucket`, `consent_policy_version`, `expires_at`, and `created_at`. They contain no query, query derivative, user, IP, result ID, or correlation ID. A row is emitted only when its cell count reaches 20; smaller cells are discarded. Retention is `A0_AGGREGATE`.

### OpenSearch document

Fields: keyword `resourceType`, keyword `sourceResourceId`, long `sourceVersion`, keyword `ownerId` where owned, keyword `visibility`, keyword `sensitivity`, keyword `permissionPolicyRef`, long `permissionVersion`, long `deletionVersion`, text/keyword `title`, text `body`, date `updatedAt`, keyword `schemaVersion`. Internal `_id` is `resourceType:sourceResourceId`; it is never public. Title boost is 3.0 and body boost 1.0 using BM25 defaults. Tie order is `_score desc, updatedAt desc, sourceResourceId asc`.

## Permission projection entities

Permission Service owns `permissions`, `consent_history`, and `privacy_settings` as defined in the source schema. M2 domain services store only opaque policy/version references. Search may store a non-authoritative projection in its index. Projection refresh or event processing cannot replace synchronous authorization.

## Reliability entities

### `legal_holds` and `legal_hold_resources`

Every data-owning service stores holds inside its own boundary. `legal_holds` contains `id`, `authority_ref`, `reason_category`, `actor_id`, `expires_at null`, `released_at null`, `released_by null`, `created_at`, `updated_at`, and `version`. `legal_hold_resources` contains `hold_id FK`, `resource_type`, `resource_id`, and `created_at`, with composite primary key `(hold_id,resource_type,resource_id)`. There is no foreign key to a polymorphic resource; the command transaction verifies ownership and existence. Index active holds by expiry and resources by `(resource_type,resource_id)`. Runtime content repositories cannot query held content through this table.

### `outbox_events`

`event_id uuid PK`, `event_type`, `event_version`, `subject_type`, `subject_id`, `subject_version`, `partition_key`, `payload jsonb`, `occurred_at`, `available_at`, `published_at null`, `attempt_count`, `last_error_code null`, `created_at`. Index unpublished `(available_at,event_id)`. Content is minimized and redacted on source purge.

### `inbox_events`

Composite PK `(consumer_name,event_id)`, `subject_id`, `subject_version`, `received_at`, `processed_at`, `result_code`. Index retention timestamp. Insert and consumer mutation occur in one transaction.

### `dead_letter_events`

`id`, `original_event_id`, `consumer_name`, `event_type`, `event_version`, encrypted minimized `payload`, `failure_code`, `attempt_count`, `first_failed_at`, `last_failed_at`, `resolved_at null`, `expires_at`. Restricted operations access only.

### `idempotency_records`

Composite unique scope fields plus `key_hash`, `request_hash`, `state` (`IN_PROGRESS|COMPLETED`), `response_status`, encrypted optional response body, response headers JSON, `created_at`, `completed_at`, `expires_at`. The raw key is not stored.

## Retention and purge

ADR-0008 classes apply exactly. `U0_ACTIVE` user-owned aggregates become immediately invisible then use `U1_DELETED` default seven days, maximum 30. Derived Search documents purge within 24 hours, maximum 72. Outbox/inbox retain 30 days, maximum 90; dead letters 30/90; audit 90/365; aggregates 30/90; memory tombstones 90/365 after purge; backups 30/90. Legal holds may delay physical purge but never visibility. Restore replays the deletion ledger before traffic and must not resurrect deleted data.
